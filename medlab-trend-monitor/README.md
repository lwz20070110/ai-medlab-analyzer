# 医学检验指标趋势动态监测系统

一款面向随访患者 / 慢病管理 / 检验教学的**轻量化趋势分析软件**，属于医工交叉（医学检验 + 人工智能）科创作品，可与「AI 医学检验智能辅助分析系统」「检验报告质控纠错系统」组成系列成果，用于职业规划大赛展示。

## 核心功能
1. **多次随访数据导入** —— 同一患者按日期排列，支持 CSV（若装有 openpyxl 可扩展 xlsx）。
2. **趋势曲线绘制** —— 选择患者与指标后自动画折线图，参考区间上下限虚线标注，超范围点红色标记。
3. **趋势自动识别** —— 基于线性回归斜率与相邻方向判断：持续升高 / 持续下降 / 波动变化 / 总体平稳。
4. **异常点标注与趋势小结** —— 自动标出超参考区间的结果，给出起点、终点、累计变化幅度与随访建议。
5. **一键导出趋势报告** —— 生成规范的文本趋势分析报告。

## 运行方式（零第三方依赖，双击即可）
```bash
# 方式一：命令行
python main.py

# 方式二：直接双击 main.py
```
> 仅需本机装有 Python 3（Windows / macOS / Linux 均可），无需 pip 安装任何包。

## 快速体验
1. 运行 main.py。
2. 点击【导入数据】选择项目内的 `示例数据.csv`（含升高、下降、波动、平稳四类样例）。
3. 选择患者与指标，点击【绘制趋势】查看曲线、异常点与趋势小结。
4. 点击【导出报告】生成规范的趋势分析文本报告。

## 趋势判断逻辑（可在 main.py 中调整）
- **持续升高 / 下降**：线性回归斜率方向明确，且相邻变化中 ≥2/3 段同向。
- **总体平稳**：累计变化与归一化斜率均很小，且无明显反复交替。
- **波动变化**：方向交替、未见明确单向趋势，建议增加随访次数。
- 参考区间在 `REF` 字典中维护，可扩充更多指标。
