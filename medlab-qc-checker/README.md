# 医学检验报告质控纠错系统

一款面向检验科报告审核 / 实习生带教的**轻量化质控辅助软件**，属于医工交叉（医学检验 + 人工智能）科创作品，可与「AI 医学检验智能辅助分析系统」配套，作为职业规划大赛的系列成果展示。

## 核心功能
1. **报告批量导入** —— 支持 CSV（若装有 openpyxl 可扩展 xlsx）。
2. **生理极值合理性校验** —— 识别小数点错位、量级错误、单位混淆等疑似录入错误。
3. **参考区间偏离分级** —— 自动分为高危 / 中危 / 提示三级，颜色标注。
4. **指标逻辑矛盾核查** —— 白细胞分类构成比之和、红细胞计数与血红蛋白方向一致性等联动校验。
5. **缺项检查与危急值标记** —— 关键指标漏检漏录自动提示。
6. **质控整改小结与报告导出** —— 按严重度汇总问题清单与复核建议。

## 运行方式（零第三方依赖，双击即可）
```bash
# 方式一：命令行
python main.py

# 方式二：直接双击 main.py
```
> 仅需本机装有 Python 3（Windows / macOS / Linux 均可），无需 pip 安装任何包。

## 快速体验
1. 运行 main.py。
2. 点击【导入报告】选择项目内的 `示例数据.csv`（已预埋录入错误、逻辑矛盾与缺项）。
3. 点击【开始质控】查看问题清单（高危红 / 中危黄 / 提示蓝）与质控小结。
4. 点击【导出报告】生成规范的质控整改文本报告。

## 质控规则说明（可在 main.py 的 QC_RULES 中扩充）
- 每项指标配置：参考下限、参考上限、生理绝对下限、生理绝对上限、单位。
- 超出生理极值 → 高危「疑似录入错误」；超参考上限一倍以上 → 高危；其余按偏离幅度分中危 / 提示。
- 逻辑矛盾：中性粒%+淋巴% 之和明显偏离 100%；RBC 与 HGB 变化方向不一致。
